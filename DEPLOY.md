## ⛔ One manual step remains: the DNS record

The domain is attached to the project and ownership is verified, but
`phuturedigital.co.za` uses **third-party nameservers** (`ns1.tld-ns.net`,
`ns2.tld-ns.com`, `ns3.tld-ns.net`, `ns4.tld-ns.com`), so Vercel cannot write
the record itself. It has to be added at the registrar:

```
Type   CNAME
Name   thorn-grain-concept
Value  b1d520db1f650ebf.vercel-dns-016.com.
```

**Use the CNAME, not the `A 76.76.21.21` the CLI suggests.** Every sibling
concept is wired this way, and a CNAME lets Vercel move the IP underneath
without anyone touching DNS again.

Once it resolves, Vercel issues the certificate automatically (usually within a
few minutes). Verify with:

```bash
vercel domains inspect thorn-grain-concept.phuturedigital.co.za \
  --scope tlotlisos-projects-5b82e36b
```

Until that record exists, **share `https://thorn-grain.vercel.app`** — it is
public and serves the current build.

⚠️ Never share a raw `thorn-grain-<hash>.vercel.app` deployment URL. Deployment
Protection is on for per-deployment URLs and recipients hit a Vercel login wall.
Only the project alias and the custom domain are public.

## Redeploying

```bash
git push origin main            # normal path — auto-deploys

vercel --prod --yes --scope tlotlisos-projects-5b82e36b   # force from local
```

After any deploy, **verify it actually took the alias** rather than assuming:

```bash
curl -sI https://thorn-grain.vercel.app | head -1
```

A sibling concept in this network sat for a week serving a months-old build
because git-triggered deployments went `● Ready` but never took the public
alias. Green in the dashboard is not the same as live.

## Before pushing

```bash
node tools/smoke.mjs        # 30 checks — must be green
node tools/charcheck.mjs    # look-alike whitespace
node tools/shoot.mjs        # 8 pages x desktop + phone, reports overflow
```

`smoke.mjs` is the one that matters: it pins the figures stated in the copy to
the catalogue and the cart arithmetic. If it is red, the site is claiming
something untrue.

## The concept network

This site is one of eight cross-linked concepts. The shared block at the foot of
every page is generated by **`insurespr/tools/stamp-network.mjs`**, which
rebuilds it from its `CONCEPTS` array.

🚨 **That script regenerates, it does not append.** Running it while a site is
missing from `CONCEPTS` silently deletes that site's card from every other site.
If you add a concept, add it to `CONCEPTS` *and* `SITES` in the same commit as
its card.

```bash
cd ../insurespr
node tools/stamp-network.mjs             # dry run — writes nothing
node tools/stamp-network.mjs --write
```

Each repo carries the thumbnails of the sites it links, in `pd-concepts/`.
Regenerate this site's own card with `node tools/shoot-thumb.mjs`.
